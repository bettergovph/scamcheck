About Scam Detector

Scam Detector is a free, open-source tool powered by AI to help protect Filipinos from phishing and spam messages.

Features

  • 🆓 100% Free - No registration required
  • 🤖 AI-Powered - Uses state-of-the-art machine learning
  • 🔒 Privacy-Focused - No data storage or tracking
  • ⚡ Fast - Instant results
  • 🌐 Open Source - MIT Licensed

How it works

Our tool analyzes your message using advanced natural language processing to detect common phishing patterns, suspicious links, urgency tactics, and other red flags commonly used in scams.
